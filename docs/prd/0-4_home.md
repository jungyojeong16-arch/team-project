## 1. 목적
로그인한 회원이 들어오자마자 **지금 상황에 맞는 작품 1편**과 랭킹·세대별 추천을 한 화면에서 본다.

## 2. 사용자 이야기
- 회원으로서, 고민 없이 "오늘 볼 것"을 하나 추천받고 바로 OTT로 가고 싶다.
- 회원으로서, 요즘 인기 작품과 내 또래가 좋아한 작품도 같이 보고 싶다.

## 3. 기능 요구사항 (Figma 위에서 아래 순서)
| ID | 영역 | 내용 | 구분 |
|---|---|---|---|
| FR1 | 상단 바 | 0-3 공통 상단 바를 그대로 사용 | 필수 |
| FR2 | 오늘의 추천 | 지금 시간대 문구(예: "저녁 · 과제 끝난 금요일 밤"), "20대 대학생 OO님, ~ 보기 좋은 신작" 한 줄, 작품 1편(배경·제목·평점·연도·등급·회차·장르·OTT·줄거리·태그), [바로 보기] [상세 정보] | 필수 |
| FR3 | 오늘의 추천 | "오늘 밤 비슷한 취향의 20대 N명이 선택했어요" — 같은 연령대 회원 중 이 작품을 추천받았거나 좋아요·평점을 남긴 사람 수 (계산값) | 선택 |
| FR4 | 통합 OTT 랭킹 TOP 10 | 순위·변동(▲▼–NEW)·평점·연도, [전체보기] → 통합 랭킹(6-1) | 필수 |
| FR5 | 세대별 교차 평점 추천 | 포스터에 마우스를 올리면 20대·30대·40대 평점 비교, 세대 간 차이가 큰 작품 표시("세대 간 호불호 차이 큼 Δ0.9") | 필수 |
| FR6 | 또래가 극찬한 작품 | 내 연령대 평균 평점 높은 순 | 필수 |
| FR7 | 하단 | 서비스 소개·약관 링크, TMDB 출처(2-1 FR9) | 필수 |
| FR8 | 로그인 안 함 | 웹 시작 화면(1-2) | 필수 |

## 4. 데이터 · API
`GET /api/v1/home/feed/` 🔒 — 응답 모양은 `app/_lib/viewfit.ts` 의 `HomeFeed` 타입을 따른다.

| 응답 칸 | 만드는 방법 |
|---|---|
| user | 닉네임·연령대·직업 (member) |
| tpo | 지금 시각 → 시간대(아침/오후/저녁/늦은 밤) + 요일. 설문을 마친 회원: 직업 + 요일 문구(예: 과제 끝난 금요일 밤)·작품 장르 태그(선호 장르 먼저) / 설문 안 한 회원: 가장 어울리는 상황 1개 |
| hero | 7-1 추천 1위 작품 (설문 안 한 회원은 선호 장르 겹치는 작품 중 평점 높은 것) + 한 줄 문구 (설문 답: ① '기억에 남는 작품' 좋아하셨다면 딱 맞을 ○○ 한 편 ② ○○ 좋아하는 취향에 딱 맞는 한 편 ③ 오늘 취향 점수 1위 ○○ 한 편, 1년 안 작품은 '신작') |
| rankings | 6-1 이번 주 랭킹 1~10위 |
| cross_age_picks | 20·30·40대 평균 차이가 큰 작품 (각 연령대 평가 3개 이상) |
| peer_picks | 내 연령대 평균 높은 순 10개 (평가 3개 이상) |

## 5. 규칙 · 예외
- 설문을 안 한 회원: 오늘의 추천 자리에 "취향을 알려주시면 딱 맞는 작품을 골라 드릴게요 [설문하기]". ✅ 11/23 (`SurveyPrompt`, 계정의 `survey_completed` 로 판단. Figma 에 이 상태가 없어서 오늘의 추천과 같은 배경)
- 내 연령대가 없거나(응답 안 함) 평가가 부족한 영역은 숨긴다.
- API 실패 시 오류 안내 + [다시 시도] (가짜 데이터로 대신하지 않음 — 지금의 대체 처리 삭제). ✅ 11/23 (404·연결 실패도 오류 안내)

## 6. 완료 기준

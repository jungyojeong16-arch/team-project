## 1. 목적
로그인한 회원이 들어오자마자 **지금 상황에 맞는 작품 1편**과 랭킹·세대별 추천을 한 화면에서 본다.

## 2. 사용자 이야기
- 회원으로서, 고민 없이 "오늘 볼 것"을 하나 추천받고 바로 OTT로 가고 싶다.
- 회원으로서, 요즘 인기 작품과 내 또래가 좋아한 작품도 같이 보고 싶다.

## 4. 데이터 · API
`GET /api/v1/home/feed/` 🔒 — 응답 모양은 `app/_lib/viewfit.ts` 의 `HomeFeed` 타입을 따른다.

| 응답 칸 | 만드는 방법 |
|---|---|
| user | 닉네임·연령대·직업 (member) |
| tpo | 지금 시각 → 시간대(아침/오후/저녁/늦은 밤) + 요일, 가장 어울리는 상황 1개 |
| hero | P09 추천 1위 작품 (P09 전에는 선호 장르 겹치는 작품 중 평점 높은 것) + 한 줄 문구 |
| rankings | P07 이번 주 랭킹 1~10위 |
| cross_age_picks | 20·30·40대 평균 차이가 큰 작품 (각 연령대 평가 3개 이상) |
| peer_picks | 내 연령대 평균 높은 순 10개 (평가 3개 이상) |

## 5. 규칙 · 예외
- 설문을 안 한 회원: 오늘의 추천 자리에 "취향을 알려주시면 딱 맞는 작품을 골라 드릴게요 [설문하기]".
- 내 연령대가 없거나(응답 안 함) 평가가 부족한 영역은 숨긴다.
- API 실패 시 오류 안내 + [다시 시도] (가짜 데이터로 대신하지 않음 — 지금의 대체 처리 삭제).

## 6. 완료 기준
- [ ] 로그인 후 홈의 작품들이 관리자 페이지 **작품** 표에 있는 진짜 작품이다

- [ ] 세대별 교차 평점의 20·30·40대 숫자가 HeidiSQL에서 직접 계산한 평균과 같다

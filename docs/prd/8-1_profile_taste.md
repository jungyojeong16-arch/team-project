## 1. 목적
내 활동(좋아요·평점)과 취향을 한눈에 보고, 취향이 바뀌면 직접 고쳐서 추천에 바로 반영한다.

## 2. 사용자 이야기
- 회원으로서, 내가 어떤 장르를 많이 보는지, 내 평점이 또래와 어떻게 다른지 보고 싶다.
- 회원으로서, 요즘 취향이 바뀌어서 선호 장르를 다시 고르고 싶다.

## 3. 기능 요구사항
### 프로필 정보
| ID | 내용 | 구분 |
|---|---|---|
| FR1 | 상단: 닉네임, 연령대·직업, 한 줄 소개(D8), 좋아요 수 · 남긴 평점 수 · 나의 평균 평점, [프로필 수정] [취향 수정] | 필수 |
| FR2 | 최근 좋아요 4개 + [좋아요 전체보기] (5-2) | 필수 |
| FR3 | 나의 시청 취향: 취향 키워드(#힐링 등), 장르 비율(상위 3개 %), 주로 찾는 시청 상황 | 필수 |
| FR4 | 최근 남긴 평점 3개 + [평점 전체보기] (5-1) | 필수 |
| FR5 | "내 평점, 또래와 비교하면?": 내가 평가한 작품들에서 내 평균 vs 같은 작품의 내 연령대 평균 ("20대 평균보다 0.3점 높아요") | 필수 |
| FR6 | 세대별 평점 미리보기: 내가 평가한 작품 1개의 20·30·40대 평균, "40대가 가장 높게 평가" + [세대별 평점 더 보기] | 선택 |
| FR7 | "2026년 3월부터 ViewFit과 함께하고 있어요" (가입일) | 선택 |

### 취향 수정
| ID | 내용 | 구분 |
|---|---|---|
| FR8 | 설문(3-1)과 같은 항목을 **기존 값이 채워진 상태**로 보여 줌: 연령대, 직업, 선호·비선호 장르, 기억에 남는 작품 | 필수 |
| FR9 | [변경사항 저장] → `PUT /me/survey/` + 추천 새로 만들기(7-1 refresh), [취소] → 프로필 | 필수 |
| FR10 | 안내: "변경사항은 저장 후 맞춤 추천에 반영돼요", "같은 장르는 동시에 선택할 수 없어요" | 필수 |

### 계산 방법 (저장하지 않음)
| 값 | 계산 |
|---|---|
| 장르 비율 | 좋아요한 작품 + 4.0점 이상 평가한 작품의 장르 개수 비율 (없으면 선호 장르 기준) |
| 취향 키워드 | 장르 비율 상위 장르 + 가장 많이 고른 상황(TPO)을 정해진 단어로 변환 (예: 로맨스 → #설렘) |
| 주로 찾는 시청 상황 | 내 추천 중 [바로 보기]를 누른 작품의 상황(tpo) 최다값 |
| 또래 비교 | 내가 평가한 작품마다 (내 점수 − 그 작품의 내 연령대 평균) 의 평균 |

## 4. 데이터 · API
| 방식 | 주소 | 내용 |
|---|---|---|
| GET | `/api/v1/me/` 🔒 | 기본 정보 + 설문 (있음 ✅) |
| GET | `/api/v1/me/profile-summary/` 🔒 | FR1~FR7 계산값 한 번에 |
| PUT | `/api/v1/me/survey/` 🔒 | 취향 저장 (있음 ✅, 3-1에서 기억에 남는 작품 추가) |
| POST | `/api/v1/recommendations/refresh/` 🔒 | 추천 새로 만들기 (7-1) |

## 5. 규칙 · 예외
- 평점·좋아요가 없으면 해당 영역에 "아직 남긴 평점이 없어요" + 둘러보기 버튼.
- 연령대 "응답 안 함"이면 또래 비교 영역을 숨긴다.
- [프로필 수정](닉네임 변경 등)은 Figma에 화면이 없어 이번 범위에서는 닉네임 변경만 팝업으로 (중복 확인 포함).
- Figma의 "프로필 예시 · 샘플 데이터" 문구는 지운다.

## 6. 완료 기준

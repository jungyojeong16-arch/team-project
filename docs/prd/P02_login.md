## 1. 목적
로그인하지 않은 방문자에게 서비스를 소개하고, 기존 회원은 이메일로 로그인해 자신의 추천을 이어서 보게 한다.

## 2. 사용자 이야기
- 처음 온 방문자로서, ViewFit이 무엇인지 한눈에 보고 가입할지 정하고 싶다.
- 기존 회원으로서, 이메일과 비밀번호로 바로 로그인하고 싶다.
- 회원으로서, 다른 사람이 쓰는 컴퓨터에서는 로그아웃하고 싶다.

## 3. 기능 요구사항
| ID | 내용 | 구분 | 상태 |
|---|---|---|---|
| FR1 | 로그인 안 한 사용자가 `/`에 오면 **웹 시작 화면**(서비스 소개 + 로그인 폼 + OTT 목록 + 회원가입 링크) | 필수 | ⬜ |
| FR2 | 이메일·비밀번호 로그인. 틀리면 "이메일 또는 비밀번호가 올바르지 않아요." | 필수 | ✅ |
| FR3 | 로그인 후 설문 안 한 회원 → 설문, 한 회원 → 홈 피드 | 필수 | ✅ |
| FR4 | **이메일 기억하기** 체크 시 다음 방문 때 이메일 자동 입력 (브라우저에 저장) | 선택 | ⬜ |
| FR5 | 상단 프로필 메뉴의 [로그아웃] → 토큰 삭제 → 웹 시작 화면 | 필수 | 🟡 (프로필 페이지에만 있음) |
| FR6 | 소셜 로그인 3개·비밀번호 찾기 버튼은 누르면 "준비 중이에요" 안내 (D4) | 선택 | ⬜ |
| FR7 | 로그인 창(Figma 161:1637)과 웹 시작 화면 모양을 Figma와 똑같이 | 필수 | ⬜ |

## 4. 데이터 · API
| 방식 | 주소 | 보내는 값 | 받는 값 |
|---|---|---|---|
| POST | `/api/v1/auth/login/` | email, password | `{token, member}` |
| POST | `/api/v1/auth/logout/` 🔒 | — | 204 (토큰 삭제) |
| GET | `/api/v1/me/` 🔒 | — | 내 정보 + `survey_completed` |

## 5. 규칙 · 예외
- 로그인 실패 시 이메일이 틀렸는지 비밀번호가 틀렸는지 알려 주지 않는다 (보안).
- 토큰이 만료·삭제되어 401이 오면 저장된 로그인 정보를 지우고 웹 시작 화면으로 보낸다.
- 이메일은 대소문자 구분 없이 로그인된다 (소문자로 저장).

## 6. 완료 기준
- [ ] 로그아웃 상태로 http://localhost:3000 → 웹 시작 화면
- [ ] 웹 시작 화면에서 로그인 → 홈 피드 (설문 안 했으면 설문)
- [ ] 비밀번호를 틀리면 빨간 안내 문구
- [ ] 이메일 기억하기 체크 후 로그아웃 → 다시 오면 이메일이 채워져 있다
- [ ] 홈 상단 프로필 메뉴 → 로그아웃 → 웹 시작 화면, 관리자 페이지의 토큰이 지워져 있다
- [ ] 카카오로 시작 → "준비 중이에요"

## 7. 범위 밖
- 소셜 로그인 실제 연동, 비밀번호 찾기 메일 발송 (D4)

## 8. 바이브 코딩 프롬프트
### Step 1 — 웹 시작 화면 (FR1, FR2, FR4, FR6)
```
docs/prd/P02_login.md 의 FR1·FR2·FR4·FR6 을 구현해 줘.
Figma 노드 179:1801 "웹 시작 화면" 을 컴포넌트로 만들고, 로그인 안 한 사용자가 / 에 오면 이 화면을,
로그인한 사용자는 지금의 홈 피드를 보여 줘.
오른쪽 로그인 폼은 app/_lib/account.ts 의 logIn 을 그대로 써.
"이메일 기억하기" 는 localStorage 에 이메일만 저장해 (비밀번호는 절대 저장하지 마).
카카오·네이버·구글로 시작, 비밀번호 찾기는 누르면 "준비 중이에요" 안내만 보여 줘.
```
### Step 2 — 로그인 창 + 로그아웃 메뉴 (FR5, FR7)
```
Figma 노드 161:1637 "로그인 창 열림" 처럼 다른 화면에서 로그인이 필요할 때 뜨는 로그인 팝업을 만들고,
지금 /login 페이지도 같은 모양으로 맞춰 줘.
Figma 노드 40:1849 의 프로필 메뉴(프로필 정보, 좋아요 표시한 작품, 나의 평점, 취향 수정, 로그아웃)를
홈 상단 프로필 동그라미를 누르면 열리게 만들고, 로그아웃은 signOut 후 / 로 이동시켜 줘.
아직 없는 페이지(좋아요·나의 평점·취향 수정)는 링크만 걸어 둬.
```

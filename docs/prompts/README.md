# ViewFit 프롬프트 사용 기록 (바이브 코딩 기록)

PRD(`docs/prd/`)를 바탕으로 **AI(Claude Code)에게 어떤 요청을 보냈고, 무엇이 만들어졌고, 어떻게 확인했는지**를 프로그램별로 남깁니다.

## 기록 방식
기록 하나는 아래 칸으로 이루어집니다.

| 칸 | 내용 |
|---|---|
| 날짜 | 요청한 날 (한국 시간) |
| 보낸 프롬프트 | AI에게 실제로 보낸 문장 (원문 그대로) |
| 기준 PRD | 이 요청이 해당하는 PRD 항목 (FR 번호, Step 프롬프트) |
| AI가 한 일 | 만들거나 바꾼 것 |
| 결과 | GitHub 커밋 링크, 바뀐 파일, 화면 캡처 |
| 확인 | PRD 완료 기준 중 직접 확인한 것 |
| 수정 요청 | 확인하다 문제가 있어서 다시 보낸 요청 |

## 진행 방식에 대한 설명 (정직하게)
- **0번·1번**: PRD와 프롬프트를 만들기 전·만든 직후라 **PRD의 Step 프롬프트를 한 글자씩 그대로 보내지는 않았고**, 정준교가 대화로 요청하면 AI가 PRD 내용을 기준으로 작업했습니다. 이 문서에는 **실제로 보낸 대화 원문**과 그 요청이 해당하는 **PRD Step**을 함께 적었습니다.
- **2번부터**: PRD의 Step 프롬프트를 **그대로 하나씩** 보내고, 그때마다 이 형식으로 기록합니다.
- 역할: 요청·확인은 정준교, 코드 작성은 AI(Claude Code), 화면 검수는 정재준, 기획 검토는 홍준화.
